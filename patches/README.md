# patches/ 许可证说明

本目录下的补丁文件（`gem5/` 43 个、`rocm-systems/` 5 个）是我们创作的原创修改，以仓库根目录 [LICENSE](../LICENSE)（GNU GPL v3.0）授权。

两点边界，如实说明：

1. 补丁所修改的**上游代码本身不因本目录而改变许可证**：gem5 上游为 BSD-3-Clause/MIT（`ext/` 内第三方为 LGPL），rocm-systems 上游为 MIT。以 GPL-3.0 授权的只是补丁文本（与合并后的衍生作品整体）。
2. 补丁文件内部不添加许可证头——那会破坏 `git apply` 的逐行对应；本 README 与根 LICENSE 共同构成对补丁的许可声明。

将补丁应用至上游代码即得到本项目的衍生构建；衍生作品的分发需同时满足 GPL-3.0 与上游文件原样保留的版权/许可声明要求（见主 README 的「许可证」小节）。
